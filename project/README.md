# 🎓 Student Record Management System

## 📌 About the Project
The Student Record Management System is a Python-based application designed to manage student information digitally. It allows users to add, view, search, update, and delete student records efficiently. The system reduces manual record-keeping and makes student data easier to organize and access.

## 🎯 Objectives
- Maintain student records digitally.
- Reduce manual paperwork.
- Search student information quickly.
- Update and delete student records easily.
- Store student information permanently using JSON file handling.

## ⚙️ Features
- Add New Student
- View All Students
- Search Student by ID or Name
- Update Student Details
- Delete Student Records
- Calculate Student Grades
- Display Student Information

## 🛠️ Technologies Used
- Python
- JSON File Handling
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling (Try-Except)

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd Student-Record-Management-System
   ```

3. Run the Python program:
   ```bash
   python3 main.py
   ```
